# Documentation overview

This folder documents the desktop client under `app/`.

The git repository root is `app/`. The stack is Tauri 2 with a Vue 3 and TypeScript frontend built by Vite. Package management uses Bun (`bun.lock` only).

The Tauri identifier is `com.attendance.app`.

## Contents

- `app/` covers setup and the current UI shell.

## Out of scope

These docs do not cover the Go server, Kotlin sensor wiring, or attendance product features. Those live elsewhere in the class project and are not part of this client scaffold yet.
