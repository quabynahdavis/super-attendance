# UI

## Current shell

`src/App.vue` centers a single shadcn-vue `Button` labeled "Click me". That is the starter surface after the UI commit; there is no attendance UI yet.

## shadcn-vue

shadcn-vue is initialized with style `reka-nova`. Configuration lives in `components.json` at the repo root.

Notable paths:

- `src/components/ui/button/` — Button component
- `src/lib/utils.ts` — shared class helper used by UI components
- `src/style.css` — Tailwind entry referenced by `components.json`

Tailwind CSS 4 is in use via `@tailwindcss/vite` and the `tailwindcss` package.

## Stack notes

The frontend is Vue 3 with TypeScript and Vite. Icons are set up for Lucide (`iconLibrary` in `components.json`). The desktop shell is Tauri 2; this file only describes the Vue UI layer.

## Out of scope

Attendance screens, sensor status, and server-backed flows are not documented here because they are not implemented in this client yet.
