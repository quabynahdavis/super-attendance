# App documentation

This section describes the Tauri desktop app in this repository.

## Stack

- Tauri 2 (`src-tauri/`, identifier `com.attendance.app`)
- Vue 3 with TypeScript
- Vite
- Bun for installs and scripts (`bun.lock` only; no npm, yarn, or pnpm lockfiles)
- Tailwind CSS 4
- shadcn-vue (style `reka-nova`)

## Topics

- `01-setup.md` — install and run commands
- `02-ui.md` — frontend UI layout and shadcn-vue pieces
